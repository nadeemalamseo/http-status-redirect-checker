MarketLatch · HTTP Diagnostics

HTTP Status & Redirect Checker

Inspect HTTP status codes, redirect chains, loops, broken URLs, destination mismatches, response types, and request errors.

View repositoryDownload ZIP
CAPABILITIES

Built for focused, practical work.

S

Status inspection

Classify 2xx, 3xx, 4xx, and 5xx responses.

R

Redirect tracing

Record redirect hops, loops, missing Location headers, and final destinations.

E

Expected destination

Compare an observed final destination with an expected URL.

C

Controlled requests

Set request timeouts and redirect limits without automatically following redirects.

WORKFLOW

From input to useful evidence.

URL → RESPONSE → REDIRECT HOP → LOOP/ERROR CHECK → FINAL DESTINATION → OPTIONAL EXPECTED MATCH
SETUP GUIDE

Clear steps, no guesswork.

1

1. Download

Get the repository ZIP or clone the source.

2

2. Install

Use Python 3.10+ and install requests.

3

3. Inspect URLs

Check one or multiple URLs you are authorized to inspect.

4

4. Evaluate the finding

A redirect is not automatically a problem; assess it against the site's architecture and intent.

QUICK START

Run it in minutes.

python -m pip install -r requirements.txt
python http_status_redirect_checker.py https://example.com/
python http_status_redirect_checker.py https://example.com/old-page --json
python http_status_redirect_checker.py https://example.com/old-page --expected-destination https://example.com/new-page
