# Code of Conduct

## Our standard

We want this project to remain a respectful, useful, and technically focused place to learn, contribute, report problems, and improve the resource.

Examples of constructive participation include:

- Giving specific, evidence-based feedback.
- Explaining problems clearly and respectfully.
- Welcoming questions from people with different levels of experience.
- Focusing criticism on the work or implementation, not on people.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, deliberate disruption, or publishing private or confidential information.

## Enforcement

Project maintainers may edit, remove, or decline contributions that violate these standards. Serious or repeated violations may result in restricting participation.

For conduct concerns, contact the maintainer through the GitHub profile rather than publishing sensitive details in a public issue.

## Attribution

This policy is adapted for this project from common open-source code-of-conduct practices, including the Contributor Covenant approach.
